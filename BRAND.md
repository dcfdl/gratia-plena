# Identidade Visual - Gratia Plena Sistemas

## Posicionamento

A Gratia Plena Sistemas cria software sob demanda para empresas que precisam digitalizar processos, integrar sistemas e evoluir operações com segurança.

## Marca

- Nome principal: Gratia Plena
- Complemento: Sistemas
- Símbolo: monograma `GP`
- Tom: consultivo, direto, técnico sem excesso de jargão

## Paleta

- Verde profundo: `#004F56`
- Verde escuro: `#073940`
- Grafite: `#102B31`
- Papel quente: `#F7F3EA`
- Superfície: `#FFFDF8`
- Dourado antigo: `#B9904D`
- Coral de destaque: `#E07A5F`
- Azul técnico: `#5E8FA6`
- Verde status: `#12A071`
- Linha neutra: `#E4DDD0`

## Tipografia

- Interface: `Inter`, com fallback para system UI
- Monograma: `Georgia`, com fallback serifado

## Direção visual

- Interfaces limpas, densas e orientadas a trabalho.
- Cantos com raio máximo de 8px.
- Ícones lineares e objetivos.
- Fundos claros com contraste em verde profundo.
- Dourado usado como detalhe institucional, não como cor dominante.

## Voz

Use frases claras e objetivas. Evite promessas vagas. Prefira explicar benefício operacional com linguagem prática: integração, segurança, processo, dados, sustentação e evolução.
